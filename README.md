Emberline Yard: an original round-based tactical FPS in three.js. A dusk-lit freight yard with two bomb sites joined by three lanes — you plus 3 ally bots vs 5 enemy bots, first to 5 rounds, with a buy-phase economy, spike planting and defusal, and bots that patrol, hold angles, rotate and defuse.

## Run it

```sh
node serve.ts
```
